# مِداد | منصة الأستاذ

واجهة عربية RTL لتنظيم العمل التعليمي، مبنية حالياً بـ HTML وCSS وJavaScript دون إطار عمل.

## تشغيل المنصة
- افتح رابط GitHub Pages المنشور من إعدادات المستودع.
- الواجهة متجاوبة مع الهاتف والحاسوب.

## الوظائف الموجودة حالياً
- لوحة رئيسية وإحصاءات.
- إدارة الأقسام والتلاميذ والدروس والتقويمات.
- تسجيل الحضور والغياب والتأخر بحسب القسم والتاريخ.
- تقارير وتصدير نسخة JSON.
- قالب إرشادي أولي لمخطط تحضير الدرس.
- ميزة «حوّل درسك إلى تجربة تعليمية ممتعة»: توليد شرح سبورة، وشرح تفاعلي، وملخص ممتع عبر Gemini؛ مع عرض مستقل وتعديل وحفظ محلي وإعادة استخدام.

## حدود النسخة الحالية
- النسخة المنشورة حالياً تحفظ البيانات في `localStorage` على المتصفح والجهاز الحالي فقط.
- لم يتم تفعيل تسجيل الدخول أو ربط قاعدة البيانات بعد.
- ميزة تحويل الدرس تتطلب نشر النسخة المحدّثة من `gemini-worker.js` على Cloudflare وإعداد سر `GEMINI_API_KEY`.
- التجارب التعليمية تحفظ حالياً في `localStorage` على الجهاز نفسه؛ لم يتم تفعيل مزامنتها عبر Supabase.
- لا تستخدم بيانات تلاميذ حقيقية أو حساسة قبل إكمال المصادقة والربط السحابي.

## تأسيس قاعدة البيانات السحابية (الخطوة الأولى)
1. أنشئ مشروع Supabase مستقلاً باسم Midad.
2. افتح **SQL Editor** في مشروع Supabase.
3. افتح الملف `supabase/schema.sql` في هذا المستودع وانسخ محتواه كاملاً إلى SQL Editor ثم اضغط **Run**.
4. احتفظ برابط المشروع و **anon / publishable key** لاستخدامهما في إعداد الواجهة لاحقاً.
5. لا تشارك أبداً `service_role key` أو كلمة مرور قاعدة البيانات، ولا تضعهما في ملفات الموقع.

يتضمن المخطط جداول ملفات الأساتذة والأقسام والتلاميذ والدروس والتقويمات والحضور، مع تفعيل Row Level Security وسياسات تجعل كل أستاذ يصل إلى سجلاته فقط. هذا المخطط لا يعني أن الواجهة متصلة بقاعدة البيانات بعد؛ سيأتي ربط الواجهة وتسجيل الدخول في الخطوة التالية.

## الخطوات التالية
1. ربط تسجيل دخول الأستاذ عبر Supabase Auth.
2. نقل بيانات الواجهة من التخزين المحلي إلى قاعدة البيانات.
3. إضافة إدارة جلسة الدخول وتسجيل الخروج وحماية الصفحات.
4. ربط مساعد التحضير بخدمة ذكاء اصطناعي عبر خادم آمن بعد إعداد الخدمة.
