# مِداد | منصة الأستاذ

واجهة عربية RTL لتنظيم العمل التعليمي، مبنية بـ HTML وCSS وJavaScript دون إطار عمل.

## تشغيل المنصة
- افتح ملف `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع ليصبح الموقع متاحاً عبر رابط عام.
- الواجهة متجاوبة مع الهاتف والحاسوب.

## الوظائف الموجودة في هذه النسخة
- لوحة رئيسية وإحصاءات.
- إضافة الأقسام والتلاميذ والدروس والتقويمات وحذفها والبحث فيها.
- تسجيل الحضور والغياب والتأخر بحسب القسم والتاريخ.
- ملخص تقارير وتصدير نسخة JSON من البيانات.
- قالب إرشادي ثابت لمخطط تحضير الدرس.

## حدود النسخة الحالية
هذه نسخة أولية قابلة للتجربة وليست بعد منصة إنتاجية متكاملة:
- تحفظ البيانات في `localStorage` على المتصفح والجهاز الحالي فقط.
- لا يوجد تسجيل دخول أو صلاحيات مستخدمين أو قاعدة بيانات سحابية.
- «مساعد التحضير» قالب ثابت وليس ذكاءً اصطناعياً متصلاً بخدمة خارجية.
- لا ترفع بيانات تلاميذ حقيقية أو حساسة إلى هذه النسخة التجريبية.

## الخطوات التالية
1. إضافة مصادقة آمنة للأستاذ.
2. ربط قاعدة بيانات سحابية مع صلاحيات وحماية للبيانات.
3. بناء واجهة خلفية وواجهات API.
4. ربط مساعد التحضير بخدمة ذكاء اصطناعي بعد إعداد مفاتيح الخدمة في الخادم، وليس في المتصفح.
5. إضافة اختبارات آلية والتحقق من سهولة الاستخدام وإمكانية الوصول.
