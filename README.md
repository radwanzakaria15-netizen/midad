# مِداد | مساحة الأستاذ

منصة عربية RTL لإدارة العمل التعليمي، بواجهة متجاوبة ومكوّنات بصرية ناعمة. تشمل الأقسام والتلاميذ، رفع ملفات التحضير، الحضور والغياب، التقويمات، مكتبة الموارد، الأنشطة، وتجارب التعلم المولّدة بالذكاء الاصطناعي.

## تشغيل النسخة الحالية
- افتح رابط GitHub Pages المنشور من إعدادات المستودع.
- الواجهة متجاوبة مع الهاتف والحاسوب.
- الملفات الأساسية: `index.html`، `attendance.js`، `experience.js`، `games.js`، `revision.js`، وملفات CSS المصاحبة.

## الوظائف الحالية
- إدارة الأقسام والتلاميذ.
- رفع ملفات التحضير ومعاينتها وإدارتها.
- تسجيل الحضور والغياب والتأخر بحسب القسم والتاريخ.
- إنشاء أنشطة تعليمية وألعاب قابلة للتعديل.
- إعداد التقويمات والاختبارات مع الأسئلة ومفتاح الإجابة.
- مكتبة موارد وتقارير ونسخ احتياطي JSON.
- تحويل الدرس إلى سبورة تعليمية أو شرح تفاعلي أو ملخص ممتع عبر Gemini عند إعداد Worker.
- مساعد المراجعة الذكي: توليد اختيار من متعدد وصح/خطأ وبطاقات مراجعة، مع شرح الإجابات وتحليل المفاهيم التي أخطأ فيها المتعلم. تُحفظ محاولات العرض محلياً على الجهاز حالياً.

## الحالة التقنية الحالية
- الموقع المنشور واجهة ثابتة؛ البيانات ما زالت تحفظ في `localStorage` على المتصفح والجهاز الحالي.
- لا يوجد حتى الآن تسجيل دخول مفعّل أو مزامنة بيانات مع Supabase.
- ملفات التحضير مخزنة محلياً حالياً؛ مخطط Supabase يجهز تخزيناً خاصاً للملفات.
- لا تضع بيانات تلاميذ حقيقية أو حساسة في النسخة الحالية قبل إكمال المصادقة والربط السحابي.
- لا تضع مفاتيح سرية في ملفات GitHub أو JavaScript المنشور.
- مساعد المراجعة يحتاج إلى إعادة نشر `gemini-worker.js` المحدّث على Cloudflare حتى يقبل `kind: revision`؛ تعديل ملف Worker في GitHub لا ينشره تلقائياً.

## تجهيز قاعدة بيانات Supabase
1. أنشئ مشروع Supabase مستقلاً باسم Midad.
2. افتح **SQL Editor** في المشروع.
3. افتح `supabase/schema.sql` وانسخ محتواه كاملاً إلى SQL Editor ثم اضغط **Run**.
4. المخطط يجهز ملفات الأساتذة، الأقسام، التلاميذ، ملفات التحضير وملفاتها، الأنشطة، التقويمات، الحضور، الموارد، وتجارب التعلم. كما يفعّل RLS ويقيد السجلات وملفات التخزين بصاحب الحساب.
5. احتفظ برابط المشروع ومفتاح **publishable / anon** لربط الواجهة لاحقاً. لا تشارك `service_role key` أو كلمة مرور قاعدة البيانات.

اقرأ `supabase/APP-DATA-MAPPING.md` قبل تنفيذ المزامنة؛ فهو يوضح كيفية تحويل بنية البيانات المحلية الحالية إلى الجداول السحابية، بما في ذلك ترحيل المعرّفات والملفات.

**تنبيه:** رفع مخطط SQL إلى GitHub لا ينشئ قاعدة البيانات. يجب تشغيله داخل مشروع Supabase أولاً، ثم بناء المصادقة وربط الواجهة به.

## Gemini
- خطوات نشر الخادم الوسيط وإعداد سر `GEMINI_API_KEY` موجودة في `GEMINI-SETUP.md`.
- لا تضع مفتاح Gemini داخل `index.html` أو أي ملف عام.
- راجع المحتوى الذي يولده الذكاء الاصطناعي قبل استخدامه تعليمياً، ولا ترسل بيانات شخصية للتلاميذ ضمن الطلبات.
