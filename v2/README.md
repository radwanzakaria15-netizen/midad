# مِداد V2 — النسخة التأسيسية

هذا المسار مستقل عن تطبيق الإنتاج الحالي، ولا يستبدل ملفات الجذر أو بيانات النسخة المنشورة.

## التشغيل
افتح `v2/index.html` عبر متصفح أو انشر المستودع عبر Cloudflare Pages. بعد نشر الفرع يمكن فتح المسار `/v2/`.

## المنفذ في هذه المرحلة
- واجهة عربية RTL بتصميم متجاوب للهاتف والحاسوب.
- لوحة تحكم وواجهة تنقل للأقسام الرئيسية.
- إدارة الأقسام والتلاميذ: إضافة وتعديل وحذف.
- تسجيل الحضور حسب التاريخ والحالة.
- نماذج التحضير البيداغوجي والأنشطة والتقويم والموارد.
- تقارير أولية وتصدير نسخة JSON.
- وضع ليلي.
- حفظ محلي عبر `localStorage`.

## حدود المرحلة
هذه نسخة تأسيسية للواجهة وسير العمل. البيانات محفوظة في المتصفح الحالي فقط، وليست مزامنة سحابية. لا تستخدمها لتخزين بيانات حقيقية حساسة للأطفال. لم يتم ربط Supabase Auth أو قاعدة بيانات سحابية أو تخزين ملفات أو API للمساعد الذكي في هذا المسار بعد. هذه هي الأعمال التالية قبل اعتمادها للاستخدام الفعلي.
